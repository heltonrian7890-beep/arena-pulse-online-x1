# Arena Pulse X1 Online

## Como rodar no PC

1. Instale Node.js
2. Abra o terminal dentro desta pasta
3. Rode:

npm install

4. Depois rode:

npm start

5. Abra:

http://localhost:3000

## Como jogar online

Para outra pessoa de outra cidade jogar, você precisa hospedar esse projeto em Render, Railway, VPS ou outro servidor Node.js.
